# BUNORA — Premium Burger Experience

BUNORA is a modern, responsive burger restaurant website designed to deliver a premium online food-ordering experience.

This project was created as a frontend development and web design portfolio project.

## Live Demo

[BUNORA Live Website](https://fantastic-syrniki-e4de7e.netlify.app)

## Features

- Modern and premium user interface.
- Responsive design for desktop, tablet, and mobile.
- Arabic and Turkish language support.
- RTL and LTR layout support.
- Interactive food menu.
- Product search and category filtering.
- Product details with customizable add-ons.
- Interactive shopping cart.
- Dynamic price calculations.
- Demo checkout with delivery and restaurant pickup options.
- Unique order number generation.
- Previous orders history.
- LocalStorage persistence for cart and orders.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## Project Type

Frontend Development / Portfolio Project

This is a demonstration website. It does not process real payments or send orders to a restaurant.
